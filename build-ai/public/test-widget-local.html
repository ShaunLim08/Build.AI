🔧 Integration Methods

Method 1: Declarative (Currently Used)

<script src="https://build-ai-shaun.vercel.app/widget.js"
  data-chatbot-id="690d766aaab28cbf91ac9b6b"
  data-position="bottom-right"
  data-primary-color="#ff4d00"
  data-bg-color="#ffd500"
  data-text-color="#000000"
  data-watermark="true">
</script>

Method 2: Programmatic

<script src="https://build-ai-shaun.vercel.app/widget.js"></script>
<script>
  new BuildAIChatbot({
    chatbotId: '690d766aaab28cbf91ac9b6b',
    position: 'bottom-right',
    primaryColor: '#ff4d00',
    backgroundColor: '#ffd500',
    textColor: '#000000',
    showWatermark: true,
    baseUrl: 'https://build-ai-shaun.vercel.app'
  });
</script>

🎨 Customization Options

  • chatbotId - Your chatbot's unique identifier
  • position - Widget position: bottom-right, bottom-left, top-right, top-left
  • primaryColor - Main accent color (buttons, headers)
  • backgroundColor - Chat bubble background color
  • textColor - Text color for contrast
  • showWatermark - Display "Powered by Build.AI" badge
